## PR #2：从参考图自动提取并应用画面风格

已合并 · [原始 PR](https://github.com/sykesP42/AutoToon/pull/2) · [代码变更](https://github.com/sykesP42/AutoToon/pull/2/files)

### 背景

已有插件可以调节材质参数，但参考图的整体色调、饱和度与明暗对比还需要额外处理。使用者需要能够从参考图得到一个调色起点，并决定应用强度。

### 问题

单独调整材质参数不能完整表达整体画面风格；如果自动结果直接覆盖画面，也缺少在参考图效果与原始效果之间调节的入口。

### 解决方式

- 增加 `AnalyzeImageStyle()`，解码参考图，并通过步进方式采样约 64 × 64 个位置。
- 用 RGB 均值近似主色调，用亮度标准差估计对比度，用各通道最大值与最小值的差估计色彩丰富程度，再映射为目标后处理参数。
- 将色彩增益按平均亮度归一化，减少单纯因为色偏改变整体明暗的问题。
- 增加 `ApplyStyleToWorld()`，将目标参数应用到场景后处理体积；没有可用体积时创建一个。
- 在调试界面加入分析按钮和 `StyleIntensity` 滑条，用 0 到 1 的强度插值控制应用程度。

### 成果

交付了一条可交互的“选择参考图 → 分析风格 → 调整强度 → 应用到场景”流程。它使用可解释的颜色统计生成调色参数，便于继续人工调整。PR 未提供画质评分或性能基准，因此这里将成果限定为具体能力和交互流程的实现。

## PR #1：整理训练、模型导出与引擎插件的接入流程

已合并 · [原始 PR](https://github.com/sykesP42/AutoToon/pull/1) · [代码变更](https://github.com/sykesP42/AutoToon/pull/1/files)

### 背景

当时的目标是输入一张 224 × 224 的参考图，预测六个 MooaToon 材质参数，再在 Unreal Engine 中应用。这个过程跨越 Python 训练代码、ONNX 模型和引擎插件，需要一致的数据约定。

### 问题

训练资料、参数记录、模型推理与插件使用说明需要被组织到可跟随的目录和步骤中。尤其是训练端的归一化与引擎端的参数范围必须对应，否则即使模型能运行，写入材质的值也可能不符合预期。

### 解决方式

整理 `HybriToon/ONNX` 与 `HybriToon/Plug`，加入 PyTorch 训练脚本、数据集检查、独立 ONNX 推理验证，以及用于记录、读取和应用材质参数的引擎脚本。补充 `MooaToonInference` 插件代码与使用说明。

文档明确六个输出参数的顺序，并说明描边宽度在训练时归一化、应用前还原到实际范围；同时提供把插件放入项目、编译并使用调试界面的接入步骤。

### 成果

形成了可按文档逐步验证的数据检查、训练、导出、独立推理和引擎接入路径。协作者可以先检查图片与标签，再在引擎外验证模型输出，最后进入材质应用环节。该 PR 的主要交付是实现与配套材料，没有提供可据此宣称的模型精度提升数据。
