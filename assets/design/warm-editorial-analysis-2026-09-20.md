## 一、Evolve Private Wealth — `https://evolveprivatewealth.com/`

**定位**：深色高级感 + 社论式排版。三个参考源里"质感"最强的一档。

### 1. 配色
| 角色 | 取值 | 用法 |
|---|---|---|
| 主色（大面积） | 近黑暖棕 `#2C2117` ~ `#3A2C1E` | 首屏、服务区、整段背景 |
| 反白背景 | 奶油米白 `#F2E9DA` / `#EFE6D6` | 数据区、页脚，形成"深—浅—深"节奏 |
| 主文字 | `#FFFFFF`（深底上）/ `#2C2117`（浅底上） | 只有两级，没有中间灰 |
| 次级文字 | 白 60% / 棕 55% | 仅用于说明句 |
| 强调 | 无高饱和色 | 靠明暗对比而非色相制造重点 |

**关键点**：整站只有"深棕 + 奶油"两个色相，**零彩色 accent**。这跟当前项目 `--accent:#332c1e` 的思路一致，但参考站把明暗反转用得更狠（整屏深色）。

### 2. 字体层级
| 层级 | 规格 | 特征 |
|---|---|---|
| Logo / 图腾 | 小写 `evolve`，约 200px+，字重 900，**负字距** | 文字即图形，占满首屏宽度 |
| 区块主陈述 | 衬线体（editorial serif），32–40px，字重 400，行高 1.45 | 排版靠左、单行短、大量换行 |
| 小节标题 | 无衬线 40–52px，字重 400 | "We do things differently, by design." |
| 数据大字 | 衬线 72–96px，字重 400（`$2.5B` / `100%` / `24`） | 数字本身就是视觉主体 |
| 小标签 | 无衬线 11–12px，**大写 + 字距 2–3px**，字重 600 | `Who We Are` / `Firm Highlights` |
| 正文 | 无衬线 14–15px，行高 1.7 | 灰度 55% |

**关键点**：**极小的全大写宽字距标签 + 极大的衬线标题** 形成强反差；正文只做陪衬。中文站点可直接映射为"12px 宽字距小标签 + 大号衬线中文标题"。

### 3. 间距与留白
- 区块纵向 padding：**120–170px**，首屏下方留白接近半屏。
- 陈述段落最大宽度约容器的 **60–64%**，右边大量空。
- 标签与内容之间：64px 左右的分栏空隙，靠一条 **1px 极低对比细分线** 分隔。
- 元素级间距：8 / 16 / 26 / 40px 四档为主。

### 4. 组件样式
- **按钮**：全圆角胶囊（`border-radius: 999px`），白底黑字，内边距约 `9px 22px`，文字 11–12px 大写宽字距。导航里的 `Client Login °` 带一个结尾小圆点符号。
- **卡片**：几乎不用阴影，用 **1px 细描边 + 冷暖色差** 划界；数据区三栏靠竖线分隔。
- **导航**：透明 → 深色，右侧一个胶囊 CTA，左中右三段式。
- **图标**：细线描边（1px），单色，装饰性插画（条纹、圆环）用同色系低对比。
- **分隔线**：全站统一的 1px 低对比线，是主要的"结构语言"。

### 5. 整体布局
- `左 小标签 / 右 大段内容` 的两栏制，反复出现。
- 首屏：巨型 logotype 在上，导航浮在 logotype 下方偏右，主标题 `Adaptive Wealth.` 压在中下部 —— **打破常规的垂直居中，靠字号权重排序**。
- 深色区与浅色区交替，每段都接近满屏高。
- 页脚：左侧大 logo 图形 + 中间导航列表 + 右侧地址/联系，三栏。

**截图**：`evolve-1-hero.png`（首屏）、`evolve-2.png`（陈述区/两栏）、`evolve-3.png`（数据三栏）、`evolve-4.png`（服务详情 + 胶囊按钮）、`evolve-5.png`（页脚）

## 二、Awwwards — `https://www.awwwards.com/`

**定位**：白底 + 超大字 + 网格化卡片。代表"作品集/列表页"的现代范式。

### 1. 配色
| 角色 | 取值 |
|---|---|
| 背景 | 纯白 `#FFFFFF` / 米白 `#F8F7F4` |
| 主文字 | 近黑 `#141414` |
| 次级文字 | `#6E6E6E` |
| 描边 | `#E4E4E4`（1px） |
| 强调 | 单一黄色（laurel 奖杯）+ 黑底白字反白胶囊 |

### 2. 字体层级
- 层级 **完全靠字重 + 字号**，不靠颜色：
  - 页面大标题（`NOMINEES` / `PENSATORI IRRAZIONALI`）：**90–120px，大写，字重 800–900，字距略收紧，居中**
  - 区块小引子（`Latest` / `Site of the Day`）：13px，灰，居中
  - 卡片标题：16px / 600
  - 标签 chips：11px 大写，1px 描边胶囊
  - 正文：15px / 400，灰
- 字体族单一无衬线（近似 Inter Tight），全站一种字体，靠 400/600/900 三档拉层级。

### 3. 间距与留白
- 首屏标题上下各约 60–90px 空白。
- 卡片网格：3 列，**列间距 20–24px，行间距 40–56px**（行距明显大于列距，让每张卡有"标题区"呼吸）。
- 容器左右 padding：约 40px（1440 宽下）。

### 4. 组件样式
- **筛选条**：一排 999px 全圆角描边胶囊（`Awards` `Category` `Tag` `Technology` `Country` `Font` `Color`），高约 48px，1px 描边，hover 变实底。
- **卡片**：缩略图圆角 **约 8–12px**，**无阴影**；hover 才浮起。卡下是「小头像 + 名字 + 描边小徽章（`DEV` / `SOTD`）+ 右侧外链图标」。
- **悬浮工具条**：黑底圆角胶囊（含 `W.` logo / `Nominees` / `Visit Sotd` 白底按钮），固定在视口底部中间 —— 一个很值得抄的细节。
- **导航**：白底、左侧 hamburger + logo、中间搜索框（圆角 999px 浅灰底）、右侧 `Log in / Sign up / Be Pro（黑底胶囊）/ Submit Website（描边胶囊）`。

### 5. 整体布局
- 自上而下：促销细条 → 导航 → 筛选条 → `列表标题 + 计数` → 3 列卡片网格 → 无限滚动。
- 标题永远居中；列表永远是 3 列对齐网格。
- 详情页：米白底 → 居中超大标题 → 圆形 `SOTD` 徽章 + 右侧三个圆形图标按钮 → 大尺寸圆角预览图（带浏览器工具栏的 mock）。

**截图**：`awwwards/home-top.png`、`awwwards/sotd-list-top.png`、`awwwards/sotd-list-grid.png`、`awwwards/sotd-tuscan-top.png`（详情页）

### 2b. Awwwards 获奖站示例 — The Tuscan Journey（`weekend-mm-2026-pasticcino-bag-master.monogrid.io`）
- **配色**：暖棕 / 橄榄绿 / 奶油白的大地色系，整体复古旅行绘本质感。
- **字体**：超大无衬线标题（`TUSCAN JOURNEY` 约 72px，字重 800）压在橄榄绿手绘毛边框内；上方 14px 字距 6px 的 `THE`；下方 13px 字距 4px 的 `BEGINS`。
- **组件**：米白胶囊按钮 `Start now`，上下缘带手绘波浪边。
- **布局**：整屏固定，四周是一圈深棕手绘毛边相框（`border/inset shadow` 做旧），内容全部压在中央安全区。

**截图**：`awwwards/sotd-tuscan-site-hero.png` / `-s2.png` / `-s3.png`

## 三、One Page Love — `https://onepagelove.com/`

**定位**：米色底 + 极简排版 + 收录详情页。三个源里**最接近"内容型单页"的排版规范**，与中文信息型站点最适配。

### 1. 配色
| 角色 | 取值 |
|---|---|
| 背景 | 米白 `#F2EFE9`（略带暖调）/ 卡片纯白 `#FFFFFF` |
| 主文字 | 近黑 `#1E1E1E` |
| 次级文字 | 暖灰 `#8A8580` |
| 描边 | `#E3DFD7`（1px） |
| 强调 | **单一玫红/朱红** `#E8384F`（订阅按钮、VISIT WEBSITE 按钮、小爱心 logo） |

**关键点**：米色底 + 唯一的玫红 accent —— 既有暖调，又保证 CTA 一眼可见。当前项目 `--sun:#d4b878` 太弱，CTA 用了 `--accent` 深棕，缺少"唯一高饱和色"这个抓手。

### 2. 字体层级
| 层级 | 规格 |
|---|---|
| 首屏主标题 | 36px / 400 / 近黑，居中，「One Page websites, curated」 |
| 首屏副文 | 17px / 400 / 暖灰，居中 |
| 详情页标题 | 34px / 500，**左对齐** |
| 正文段落 | 18px / 400 / 暖灰 / 行高 1.75，最大宽度约 **62ch** |
| 卡片标题 | 16px / 600 / 近黑 |
| 卡片标签 | 13px / 400 / 暖灰 |
| 元数据标签 | 11px / 600 / 暖灰 / 大写 + 字距 1.5px |
| 标签 chips | 12px / 400，1px 描边胶囊，`padding: 4px 12px` |

### 3. 间距与留白
- 首屏：标题/副文/表单三段之间各 20–24px，整体距顶部约 90px。
- 卡片网格：3 列，列距 28px，行距 **64px**（比 awwwards 更松）。
- 详情页：内容最大宽度约 720px 居中；标题 → 描述 20px；描述 → FEATURES 32px；FEATURES → 元数据表 32px。
- 元数据表：行高 ≈ 31px，标签列与值列固定两栏。

### 4. 组件样式
- **按钮**：玫红实底胶囊，13px 大写 + 字距 1px，`padding: 10px 22px`，无阴影；次级是"下划线文字链接"（`Broken Link?`）。
- **卡片**：白色圆角 **约 8px** + 1px 浅描边 + **极轻阴影**（`0 1px 2px rgba(0,0,0,.04)`），截图满铺；卡片右上角一个 14px 的极细外链图标。
- **输入框**：白底、1px 描边、左侧圆角、右侧与按钮无缝拼接（组合成一个胶囊）。
- **导航**：透明/半透明浅底，左侧红心 logo + 站名，中间 5 个导航项（14px 灰），右侧圆角搜索框，底部 1px 分隔线。
- **引导箭头**：详情页两侧极简圆形描边按钮（36px），半透明。

### 5. 整体布局
- 首页：居中 hero（无大图）→ 3 列卡片网格 → 分页。
- 详情页：**单列居中**，`标题 → 作者行 → 描述 → 标签 chips → 元数据两栏表 → 大图预览`。信息密度低、留白足。
- 所有内容都靠"单列 + 固定最大宽度 + 左对齐文字块"约束，没有花哨分栏。

**截图**：`onepagelove/home-top.png`、`onepagelove/home-grid.png`、`onepagelove/kontu-top.png`、`onepagelove/kontu-s2.png`、`onepagelove/spatial-top.png`、`onepagelove/spatial-s2.png`

## 四、三站对本项目的可迁移结论

| 维度 | 当前项目现状 | 参考站做法 | 建议取用 |
|---|---|---|---|
| 配色 | 米白底 + 深棕 accent，`--sun` 金黄点缀但存在感弱 | 双色相 + **唯一高饱和 accent** | 保留暖白/深棕，把 `--sun` 提级为真正的强调色（按钮/下划线/数字） |
| 字体 | 全站单一无衬线，靠 `letter-spacing: 4–12px` + 字重 900 拉层级 | 小号大写宽字距标签 ↔ 大号衬线/超粗标题的**强反差** | 中文标题试试衬线（思源宋体/Noto Serif SC），英文小标签保留宽字距 |
| 间距 | 区块 padding 150px，但内部卡片密度偏高 | 区块 120–170px + 段内元素 8/16/26/40 四档 | 保持区块留白，收紧规则统一到 4 档间距变量 |
| 组件 | **全部 `border-radius: 0`（直角）**，卡片有 hover 阴影 | 卡片 8–12px 圆角、无阴影靠描边；按钮 999px 胶囊 | 二选一：要么全胶囊（参考站主流），要么保持直角但**去掉 hover 阴影改用描边变化**，避免"半直角半阴影"的混合感 |
| 布局 | 居中标题 + 4/3/2 列网格 | 左标签 + 右内容的社论两栏（Evolve）；单列 62ch 约束（OPL） | 长文本区块改成"左小标签 + 右大段"两栏，正文限宽到 62–72ch |
