# Logo Sources

- `git-icon.svg`: Git official logo download, https://git-scm.com/images/logos/downloads/Git-Icon-1788C.svg
- `go-logo.svg`: Go official brand asset, https://go.dev/blog/go-brand/Go-Logo/SVG/Go-Logo_Blue.svg
- `go-zero-logo.webp`: go-zero official website logo asset, https://go-zero.dev/_astro/logo.D3t9r_YR_uToCh.webp
- `openai-logo.svg`: derived from the OpenAI official `openai/apps-sdk-ui` logo component, https://github.com/openai/apps-sdk-ui/blob/main/src/components/Icon/svg/OpenaiLogoBold.tsx
- `mcp-logo.svg`: Model Context Protocol official site favicon, https://modelcontextprotocol.io/favicon.svg
- `dubbo-logo.png`: Apache Dubbo official logo repository, https://raw.githubusercontent.com/apache/dubbo-logo/master/DUBBO%20logo%E5%93%81%E7%89%8C%E8%89%B2.png
- `seata-logo.png`: Apache Seata official website logo asset, https://seata.apache.org/img/seata_logo.png
- `dubbo-seata-cover.png`: local composite made from `dubbo-logo.png` and `seata-logo.png`.
